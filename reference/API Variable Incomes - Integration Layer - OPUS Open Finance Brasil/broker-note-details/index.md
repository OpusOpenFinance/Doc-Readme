---
title: Broker Note Details
excerpt: >-
  Obtém as informações da nota de negociação identificado nas movimentações de
  compra e venda de ativos em bolsa.

  O brokerNoteId é enviado nos movimentos de compra ou venda de ativos e deve
  ser passada como parâmetro de entrada no endpoint “Nota de Negociação”.Como
  conteúdo do campo brokerNoteId é esperado que a transmissora gere um
  identificar único, imutável, para cada número (natural) de nota de negociação.
